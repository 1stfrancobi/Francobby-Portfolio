# Francis Cobbinah Portfolio

A responsive portfolio presenting data analysis, visualization,
machine-learning research and geospatial project contributions.

Built with plain HTML and CSS. No build step, JavaScript or external
dependencies are required.

## Pages and files

- index.html — Main portfolio, analytical projects and project contributions.
- generic.html — Complete GRACE/GRACE-FO research overview.
- elements.html — Shared design components.
- styles.css — Website styling and responsive layouts.
- images/ — Project screenshots.
- LICENSE.txt — Original MIT license.

## Required images

Keep the following files inside the images folder:

- Bike_Share_Dashboard.png
- Data_Analysis_with_Python.png
- Rplot.png

Keep filenames and capitalization unchanged.

## Portfolio structure

The homepage contains:

1. About
2. Research and analytical projects
3. Technical capabilities
4. Project contributions
5. Education
6. Contact information

Project contributions focus on work performed, methods and outputs.
Descriptions retain appropriate distinctions between work supported
and work completed personally.

## Research overview

The existing filename generic.html now contains the research overview.

It includes:

- Research problem
- Analytical approach
- Personal contribution
- Evaluation principles
- Interpretation and limitations
- Project outputs
- Skills demonstrated

The homepage research button links to generic.html.

## Preview locally

Open index.html in a browser.

Alternatively, run this command inside the website folder:

    python -m http.server 8000

Then visit:

    http://localhost:8000

## Updating the website

Replace the matching HTML, CSS and README files.

Keep the images folder beside index.html and retain LICENSE.txt.

Review changes before publishing. Pushing changes to an existing
hosting branch may publish the website automatically.
