# Francis Cobbinah Portfolio

A responsive portfolio covering data analysis, visualization,
machine-learning research and geospatial work.

Built with plain HTML and CSS. No build step, JavaScript or external
dependencies are required.

## Files

- index.html — Main portfolio and project gallery.
- generic.html — GRACE/GRACE-FO research overview.
- elements.html — Reusable design components.
- styles.css — Shared styling and responsive layouts.
- images/ — Original project screenshots.
- LICENSE.txt — Original MIT license.

## Required images

Keep these files inside the images folder:

- Bike_Share_Dashboard.png
- Data_Analysis_with_Python.png
- Rplot.png

Filenames are case-sensitive on many hosting services.

## Preview

Open index.html in your browser.

Alternatively, run this command inside the website folder:

    python -m http.server 8000

Then visit:

    http://localhost:8000

## Updating the existing repository

Replace the matching HTML, CSS and README files.
Keep the images folder alongside index.html.
Keep the original LICENSE.txt.

All local links use relative paths.

Review the site before committing changes. Pushing to a configured
hosting branch may automatically publish the update.

## Content notes

- Original project images, email and social links are retained.
- The Python histogram is presented as a visualization example.
- SQL optimization expertise is omitted pending supporting evidence.
- Dashboard and restaurant charts are static images.
- Exact model scores and business outcomes have not been invented.
- The original R chart has a cropped title. Replace it with a complete
  export when available.
